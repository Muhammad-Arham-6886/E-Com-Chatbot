Embed an intelligent, local AI-powered chatbot and WooCommerce sales assistant on your website.

== Description ==

AI Customer & Commerce Assistant connects your WordPress & WooCommerce store to your local AI / RAG multi-tenant platform.

Features:
* Automatic zero-theme widget embedding in `wp_footer`.
* Real-time local RAG grounding using your crawled website knowledge.
* Interactive product recommendation cards with image, price, and direct Add-to-Cart actions.
* WhatsApp click-to-chat human handoff bridge with pre-filled customer inquiry context.
* Human agent takeover support from the SaaS dashboard.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/ai-commerce-assistant` directory, or install the plugin through the WordPress plugins screen directly (`.zip`).
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the Settings -> AI Assistant screen to configure your Public Site ID and SaaS API URL.
